# Local setup

1. In the [server](./server) folder, add a .env file with the following contents:
```
GOODREADS_EMAIL=<your Goodreads email account>
GOODREADS_PASSWORD=<your Goodreads password>
```
2. In the [server](./server) folder, run `npm install && npm start`.
3. In the [client](./client) folder, run `npm install && npm start`.
4. View the web app on [localhost:3000](http://localhost:3000).
